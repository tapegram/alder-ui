alder-ui demos

al-dialog

A modal dialog around a native <dialog> that you write: Alder's renderer writes it for you (heading, close button and all), other stacks write it by hand, as here. Opened by commandfor / command="show-modal" on a button. The no-JS form comes first.

Without JavaScript

A link to the dialog's id shows it (:target); the close link # hides it. No script, no invoker commands.

Dismissible, with actions
